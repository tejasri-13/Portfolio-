## 📌 Overview

Portfolio is a professional personal portfolio website designed to help developers showcase their skills, projects, education, certifications, and contact information in a visually appealing way.

The website is fully responsive and optimized for desktop, tablet, and mobile devices.

This project is built entirely using **HTML5, CSS3, and Vanilla JavaScript** without any frameworks.

## 🏃‍♂️ How to Run the Project

### Step 1

Download or clone the repository.

### Step 2

Open the project folder.

### Step 3

Open:

```text
index.html
```

in your browser.

### Using VS Code

1. Install VS Code.
2. Install the Live Server extension.
3. Open the project folder.
4. Right-click `index.html`.
5. Select **Open with Live Server**.
